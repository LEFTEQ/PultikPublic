# Notices

`Sources/CodeThemes/Resources/themes.json` holds colour values taken from the
works below. Each theme's `provenance` names its exact source and version.

| Theme | Source | Licence |
|---|---|---|
| Adeberry Amber | Ours | This repository's terms |
| Codex Dark | ChatGPT.app's bundled `codex-dark` theme (OpenAI); private builds only, the public definition leaves it out | None published |
| Atom One Dark | atom/atom `packages/one-dark-syntax` 1.8.4 | MIT, below |
| GitHub Dark | primer/github-vscode-theme 6.3.5 (GitHub Dark Default) | MIT, below |
| One Light | atom/atom `packages/one-light-syntax` 1.8.4 | MIT, below |
| Tokyo Night | enkia/tokyo-night-vscode-theme 1.1.2 (Tokyo Night) | MIT, below |

GitHub Dark's selection colour is VS Code's default dark selection
(microsoft/vscode, MIT, Copyright (c) 2015 - present Microsoft Corporation).

Cursor Dark is not included: Cursor ships it inside its app under its end-user
licence agreement, with no licence of its own, and the copies published
elsewhere are repackagings whose licences cannot grant rights to it. Tokyo
Night takes its place.
